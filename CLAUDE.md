# CLAUDE.md

This repository uses `AGENTS.md` as the canonical root agent instruction file.

Before changing code or issues, read:

1. `AGENTS.md`
2. `issues/00-VERSION-2-ISSUE-INDEX.md`
3. The selected Version 2 epic and subtask
4. Only the canonical docs referenced by that task

Do not scan both child repositories by default. The frontend and backend
submodules own their own implementation details; the root repository owns
cross-repository coordination, canonical docs, issues, integration scaffolding,
and compatible submodule revision pins.
